Run the engine.

This page downloads the actual chemistry-engine wheel and runs it with Pyodide, a Python runtime compiled to WebAssembly. No server, no API keys — the same formulas, rational balancing, and stoichiometry as the CLI.

Python runtime not loaded. The first run downloads about 12 MB and can take a minute on a slow connection.

Groups, hydrates, charges, Unicode subscripts, and e^- all work.

Elemental masses and mass percentages, in Hill order.

Arrows: ->, →, =>, =; ions like Fe^2+.
