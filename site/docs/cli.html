Synopsis

chem [-h] [--version] [--json] COMMAND ...

COMMAND
  element      look up one element
  elements     list all 118 elements
  mass         molar mass of one or more formulas
  inspect      parse a formula and show its composition
  composition  elemental mass percentages
  balance      balance a chemical equation
  stoich       limiting reagent and product amounts

--json is accepted before or after the subcommand. Every subcommand returns exit code 0 on success and 2 on a chemistry or parse error.

Commands

CommandWhat it doesExample
elementResolve one element by atomic number, symbol, or English name.chem element Fe
elementsList every element and its mass.chem elements
massMolar mass of one or more formulas.chem mass H2O C6H12O6
inspectParsed atom counts, charge, canonical formula, molar mass.chem inspect "CuSO4·5H2O"
compositionElemental masses and mass percentages in Hill order.chem composition H2O
balanceBalance an equation and show the conservation checks.chem balance "Fe + O2 -> Fe2O3"
stoichLimiting reagent and amounts from mol or mass feeds.chem stoich --equation ... --feed ...

Formula notation

Formulas are parsed chemically, not with a regex. Element symbols are case-sensitive: Co is cobalt, CO is carbon monoxide.

FormExampleNotes
CountsH2O, C6H12O6Implicit 1; leading zeros rejected.
GroupsCa(OH)2, K4[Fe(CN)6]Nested (), [], {}.
HydratesCuSO4·5H2O, CuSO4.5H2O·, ., and * separators.
Fractional hydratesCaSO4·½H2OUnicode fractions up to eighths.
ChargesSO4^2-, SO4²⁻, NH4+Caret, Unicode superscript, or bare trailing sign.
Unicode subscriptsH₂ONormalized to counts.
Electrone^-Zero atoms, charge −1; used for half-reactions.
 
$ chem inspect "CaSO4·½H2O"
formula    : CaSO4·½H2O
charge     : 0
atoms      : Ca 1, H 1, O 4.5, S 1
molar mass : 145.142 g/mol

Equations

Arrows may be written as ->, →, =>, or =. Reversible arrows (<=>, ⇌, ↔) are preserved in the output.

Input coefficients are hints, not answers: chem balance "2H2 + O2 -> 2H2O" re-derives the smallest integer solution and returns the same coefficients. Ionic equations must spell out charges so the engine can conserve them: 

$ chem balance "Fe^2+ + MnO4^- + H^+ -> Fe^3+ + Mn^2+ + H2O"
5Fe^2+ + MnO4^- + 8H^+ -> 5Fe^3+ + Mn^2+ + 4H2O

Atom check (elements in equation order):
  Fe: 5 = 5
  Mn: 1 = 1
  O: 4 = 4
  H: 8 = 8
Charge: 17 = 17

Some equations have more than one independent balance. The engine returns a smallest valid integer solution and prints a note; the Python API exposes is_unique=False for those cases.

Stoichiometry feeds

--feed is repeatable and accepts moles or mass. Every reactant in the equation must be fed; feeding a product is rejected. 

chem stoich --equation "N2 + 3H2 -> 2NH3" --feed "N2=28 g" --feed "H2=6 g"
UnitMeaning
mol, mmol, umolAmount of substance.
g, kg, mg, ugMass, converted with the formula's molar mass.

JSON output

Every command accepts --json. For example:

$ chem mass --json H2O
[
  {
    "formula": "H2O",
    "molar_mass_g_per_mol": 18.015
  }
]

chem balance --json exposes coefficients, per-element conservation checks, net charge, and is_unique. chem stoich --json exposes the feed, consumed, remaining, produced, and mass maps.

Errors

Parse errors carry a column pointer on stderr and exit with status 2: 

$ chem mass "Xx2"
chem: error: invalid formula 'Xx2' at column 1: unknown element symbol 'Xx'
  Xx2
  ^
$ echo $?
2
