Getting started

Install chemistry-engine, verify the CLI, and run your first calculation. Python 3.10 or newer.

Install

The engine has no runtime dependencies. Install the prebuilt wheel from the v0.1.0 release:

Wheelterminal
pip install "https://github.com/mty2024/chemistry-engine/releases/download/v0.1.0/chemistry_engine-0.1.0-py3-none-any.whl"

Or install directly from the tagged source:

pip install "git+https://github.com/mty2024/chemistry-engine@v0.1.0"

For development, install the checkout in editable mode:

git clone https://github.com/mty2024/chemistry-engine.git
cd chemistry-engine
python -m pip install -e .

chemistry-engine is not published on PyPI yet. Use the wheel attached to the release, or the git tag above. PyPI publication is not set up.

Verify

$ chem --version
chem 0.1.0
$ chem mass H2O
H2O  18.015 g/mol

From a checkout you can skip installation entirely: python -m chemistry_engine mass H2O.

First calculations

Balance an equation

$ chem balance "Fe + O2 -> Fe2O3"
4Fe + 3O2 -> 2Fe2O3

Atom check (elements in equation order):
  Fe: 4 = 4
  O: 6 = 6
Charge: neutral (0 = 0)

Elemental composition

$ chem composition C6H12O6
formula    : C6H12O6
molar mass : 180.156 g/mol

Elem  Name        Atoms   Mass (g/mol)    Mass %
C     Carbon          6         72.066    40.002
H     Hydrogen       12         12.096   6.71418
O     Oxygen          6         95.994   53.2838

Limiting reagent

$ chem stoich --equation "N2 + 3H2 -> 2NH3" --feed "N2=1 mol" --feed "H2=2 mol"
Balanced equation: N2 + 3H2 -> 2NH3
Reaction extent  : 0.666667 mol
Limiting reagent : H2

Products:
  Species       Produced (mol)     Mass (g)
  NH3                  1.33333       22.708

Run the tests

python -m unittest discover -s tests -v
python tools/verify_chemistry.py

The suite has 82 tests. The verification script also cross-checks atomic masses against a PubChem snapshot, re-balances 19 textbook equations, and checks stoichiometric mass conservation.
