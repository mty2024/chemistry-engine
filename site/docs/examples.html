Water formation

The simplest balance: two hydrogen molecules and one oxygen molecule give two waters.

$ chem balance "H2 + O2 -> H2O"
2H2 + O2 -> 2H2O

Atom check (elements in equation order):
  H: 4 = 4
  O: 2 = 2
Charge: neutral (0 = 0)

Propane combustion

Exact integer coefficients fall out of the conservation system; nothing is guessed.

$ chem balance "C3H8 + O2 -> CO2 + H2O"
C3H8 + 5O2 -> 3CO2 + 4H2O

Atom check (elements in equation order):
  H: 8 = 8
  C: 3 = 3
  O: 10 = 10
Charge: neutral (0 = 0)

Permanganate oxidation

A classic textbook balance, including the chlorine that does not end up in a salt.

$ chem balance "KMnO4 + HCl -> KCl + MnCl2 + Cl2 + H2O"
2KMnO4 + 16HCl -> 2KCl + 2MnCl2 + 5Cl2 + 8H2O

Atom check (elements in equation order):
  K: 2 = 2
  Mn: 2 = 2
  O: 8 = 8
  H: 16 = 16
  Cl: 16 = 16
Charge: neutral (0 = 0)

Ionic redox with charge conservation

Charges are conserved alongside atoms. Here both sides have a net charge of +17. 

$ chem balance "Fe^2+ + MnO4^- + H^+ -> Fe^3+ + Mn^2+ + H2O"
5Fe^2+ + MnO4^- + 8H^+ -> 5Fe^3+ + Mn^2+ + 4H2O

Atom check (elements in equation order):
  Fe: 5 = 5
  Mn: 1 = 1
  O: 4 = 4
  H: 8 = 8
Charge: 17 = 17

With the Python API the charge totals are fields:

from chemistry_engine import balance_equation

reaction = balance_equation("Fe^2+ + MnO4^- + H^+ -> Fe^3+ + Mn^2+ + H2O")
reaction.charge_left    # 17
reaction.charge_right   # 17

Hydrate stoichiometry

The pentahydrate is a single formula. One mole of it produces one mole of anhydrous copper sulfate and five moles of water — with masses. 

$ chem stoich --equation "CuSO4·5H2O -> CuSO4 + 5H2O" --feed "CuSO4·5H2O=1 mol"
Balanced equation: CuSO4·5H2O -> CuSO4 + 5H2O
Reaction extent  : 1 mol
Limiting reagent : CuSO4·5H2O

Reactants:
  Species       Fed (mol)  Consumed (mol)  Remaining (mol)  Remaining (g)
  CuSO4·5H2O            1               1                0              0

Products:
  Species       Produced (mol)     Mass (g)
  CuSO4                      1      159.602
  H2O                        5       90.075

When an equation has more than one balance

C + O2 -> CO + CO2 can be balanced in several independent ways (pure CO, pure CO2, or a mixture). The engine returns a smallest valid integer solution and says so rather than pretending the answer is unique. 

$ chem balance "C + O2 -> CO + CO2"
3C + 2O2 -> 2CO + CO2

note: more than one independent balance exists; showing the smallest positive integer solution.

Atom check (elements in equation order):
  C: 3 = 3
  O: 4 = 4
Charge: neutral (0 = 0)

In Python, the same fact is a field on the result:

from chemistry_engine import balance_equation

balance_equation("C + O2 -> CO + CO2").is_unique   # False

Elemental composition

Hill order puts carbon first, then hydrogen, then the rest alphabetically.

$ chem composition C6H12O6
formula    : C6H12O6
molar mass : 180.156 g/mol

Elem  Name        Atoms   Mass (g/mol)    Mass %
C     Carbon          6         72.066    40.002
H     Hydrogen       12         12.096   6.71418
O     Oxygen          6         95.994   53.2838
