Formulas

parse_formula(text) returns a Formula. Counts are exact Fraction values, so fractional hydrates keep exact stoichiometry. 

from chemistry_engine import parse_formula

formula = parse_formula("CuSO4·5H2O")
dict(formula.atom_counts)   # {'Cu': 1, 'S': 1, 'O': 9, 'H': 10}
formula.charge              # 0
formula.elements            # ('H', 'O', 'S', 'Cu') — periodic-table order
formula.hill_order()        # ('Cu', 'H', 'O', 'S') — display order
formula.count("O")          # 9
formula.canonical_formula() # 'CuSO4·5H2O'

Invalid input raises FormulaParseError, which carries formula, position, and message.

Balancing

balance_equation(equation) accepts a string or a parsed Equation and returns a BalancedEquation. 

from chemistry_engine import balance_equation

reaction = balance_equation("Fe^2+ + MnO4^- + H^+ -> Fe^3+ + Mn^2+ + H2O")
reaction.formula
# '5Fe^2+ + MnO4^- + 8H^+ -> 5Fe^3+ + Mn^2+ + 4H2O'
reaction.coefficients
# (5, 1, 8, 5, 1, 4)
reaction.charge_left, reaction.charge_right
# (17, 17)
reaction.is_unique
# True
AttributeMeaning
formulaFormatted balanced equation.
coefficientsInteger coefficients, reactants then products.
reactants, productsBalanced species with formula and coefficient.
element_balancesPer-element left/right totals, in equation reading order.
charge_left, charge_rightNet charge on each side.
is_uniqueFalse when several independent balances exist.
reversibleTrue for ⇌ / <=> arrows.

Stoichiometry

from chemistry_engine import Feed, stoichiometry

result = stoichiometry(
    "N2 + 3H2 -> 2NH3",
    [Feed("N2", 1, "mol"), Feed("H2", 2, "mol")],
)
result.limiting          # ('H2',)
result.limiting_reagent  # 'H2'
result.extent            # 0.6666666666666666
result.consumed          # {'N2': ..., 'H2': 2.0}
result.remaining         # {'N2': ..., 'H2': 0.0}
result.produced          # {'NH3': 1.3333333333333333}
result.product_masses    # {'NH3': 22.708...}

Feed(species, amount, unit) accepts mol, mmol, umol, g, kg, mg, or ug. Every reactant must be fed, and feeding a product is a StoichiometryError.

Errors

All deliberate errors derive from ChemError:

ErrorRaised when
FormulaParseErrorA formula is malformed or contains an unknown symbol.
EquationParseErrorAn equation lacks an arrow or has malformed species.
UnbalanceableEquationErrorNo strictly positive integer solution exists.
StoichiometryErrorA feed is invalid or a reactant is missing.
UnknownElementErrorElement lookup finds nothing.

Data and correctness

Atomic weights come from the CIAAW Abridged Standard Atomic Weights 2024. Elements without a standard weight use the longest-lived known isotope from the CIAAW radioactive-elements table. Balancing is exact rational linear algebra; no coefficient is guessed.
