What it does

Chemistry a computation engine should get exactly right.

Every number comes from real data or exact arithmetic. The engine is a library and a CLI, not a black box.

Real periodic-table data

All 118 elements with the CIAAW/IUPAC Abridged Standard Atomic Weights 2024, plus longest-lived isotope masses where no standard weight exists.

Full formula grammar

Nested groups, hydrates and adducts, fractional water of crystallisation, ionic charges, Unicode subscripts, and the electron.

Exact balancing

Rational linear algebra, charge conservation for ionic and redox equations, and the smallest positive integer solution — with multi-solution equations flagged.

Stoichiometry

Limiting reagent (including ties), consumed and remaining amounts, product masses, and excess — from mol or mass feeds.

Pure Python

Python 3.10+, standard library only. Install from the release wheel, from a git tag, or run straight from a checkout.

CLI + JSON

Run chem mass, chem balance, chem stoich and friends, with machine-readable output for every command.

From the terminal

Answers you can check by hand.

Exact coefficients, conservation checks, and the limiting reagent — the CLI prints the working, not just the result.

Balancechem balance
$ chem balance "C3H8 + O2 -> CO2 + H2O"
C3H8 + 5O2 -> 3CO2 + 4H2O
Atom check (elements in equation order):
  H: 8 = 8
  C: 3 = 3
  O: 10 = 10
Compositionchem composition
$ chem composition C6H12O6
Elem  Name        Atoms   Mass (g/mol)    Mass %
C     Carbon          6         72.066    40.002
H     Hydrogen       12         12.096   6.71418
O     Oxygen          6         95.994   53.2838
Limiting reagentchem stoich
$ chem stoich --equation "N2 + 3H2 -> 2NH3" \
    --feed "N2=1 mol" --feed "H2=2 mol"
Balanced equation: N2 + 3H2 -> 2NH3
Reaction extent  : 0.666667 mol
Limiting reagent : H2
Products:
  Species  Produced (mol)  Mass (g)
  NH3      1.33333         22.708
