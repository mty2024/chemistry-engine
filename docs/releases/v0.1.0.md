# chemistry-engine v0.1.0

First public release of **chemistry-engine**, a real chemistry engine in pure Python —
no third-party dependencies.

## Highlights

- **118 elements** with CIAAW/IUPAC Abridged Standard Atomic Weights 2024, plus
  longest-lived-isotope mass numbers for elements without a standard weight.
- **Formula parsing** for nested groups, hydrates (`CuSO4·5H2O`,
  `CaSO4·½H2O`), ionic charges (`SO4^2-`, `SO4²⁻`, `NH4+`), Unicode subscripts,
  and electrons (`e^-`).
- **Molar mass and elemental composition** — masses, fractions, percentages,
  Hill-order output.
- **Exact equation balancing** over rationals, with charge conservation for
  ionic/redox equations and detection of multiple independent balances.
- **Stoichiometry** — limiting reagent (with ties), consumed/remaining/produced
  amounts, product and excess masses.
- **CLI**: `chem mass`, `chem composition`, `chem balance`, `chem stoich`,
  `chem element`, `chem elements`, `chem inspect` (all with `--json`).

## Install

Python 3.10+.

Prebuilt wheel (attached to this release):

```bash
pip install "https://github.com/mty2024/chemistry-engine/releases/download/v0.1.0/chemistry_engine-0.1.0-py3-none-any.whl"
```

From source at this tag:

```bash
pip install "git+https://github.com/mty2024/chemistry-engine@v0.1.0"
```

From a checkout without installing:

```bash
python -m chemistry_engine mass H2O
```

## Verification

- 82 unit tests: `python -m unittest discover -s tests -v`
- Independent checks: `python tools/verify_chemistry.py` (atomic masses vs a
  PubChem snapshot, 19 textbook equations re-balanced and checked for atom and
  charge conservation, stoichiometric mass conservation < 1e-9).

## Data sources

- CIAAW Abridged Standard Atomic Weights 2024:
  <https://www.ciaaw.org/abridged-atomic-weights.htm>
- CIAAW radioactive elements (longest-lived known isotopes):
  <https://www.ciaaw.org/radioactive-elements.htm>

## Known limitations

- Balancing and stoichiometry only — no reaction prediction, equilibrium,
  thermodynamics, or kinetics.
- No SMILES/InChI, 3D coordinates, or substructure search.
- No isotope labels; hydrate multipliers are integers or Unicode fractions up to
  eighths.
- Under-determined equations are searched for a small positive solution within a
  bounded search; exotic equations needing very large coefficients may not solve.
